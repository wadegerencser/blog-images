# blog-images

Public image host for the Wireless with Wade blog pipeline.

Hero images are generated by the n8n **Blog Writer (harvested)** workflow
(`gpt-image-1`, quality high, 1536x1024) and committed here so they have a
stable public URL that can be embedded in Lerty, LinkedIn, and WordPress.

Raw URL pattern:

    https://raw.githubusercontent.com/wadegerencser/blog-images/main/hero/<slug>.png

This repo is PUBLIC by necessity - raw URLs require it. Only publication-ready
blog artwork belongs here. No drafts, no client data, no internal material.
